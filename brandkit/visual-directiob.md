# NitYog Visual Direction

## Desired Feel
- Warm
- Playful
- Soft
- Childlike
- Friendly
- Trustworthy

## Visual Style
- Creamy backgrounds
- Rounded shapes
- Soft corners
- Warm light browns
- light yellow/peach accents
- Cute but clean illustrations
- Minimal visual clutter

## Avoid
- Neon colors
- Har jagah rainbow colors
- Sharp futuristic shapes
- Very corporate styling
- Overly childish cartoon overload
- Dark / moody photography
- using dark colors
- cluttered texts 
- tight spaces
- modern SaaS UI
